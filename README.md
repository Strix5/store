Сайт интернет-магазина, в котором осуществлены:
  1. Регистрация / Авторизация.
  2. Админ-панель для добавления товаров, категорий товаров, пользователей и т.д.
  3. На главной странице по кнопке 'Начать покупки' происходит переход на страницу товаров, с таблицей категорий, находящееся левее таблицы товаров. При выборе категории, отображаются относящиеся к ней товары.
  4. Пагинация.
  5. Профиль с личной информацией и корзиной товаров, где можно перейти к оформлению заказа, либо удалить не нужный товар.
  6. Оформление заказа с помощью стороннего веб-сервиса Stripe.
  7. Навигационная панель, где также отображается кнопка 'Админ-панель', при условии, что пользователь является сотрудником или администратором сайта.
  8. Страница заказов, произведённых пользователем.

Сайт написан на Django/DRF.
